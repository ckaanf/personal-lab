# Q · 함정

실제로 깨졌던 것. 블록을 만든 뒤 이 목록과 대조한다.

### Q-01 · 붙어 있어야 할 머리 줄이 스크롤하면 사라짐
- 증상: 한 화면 넘게 내리면 윗줄·표 머리가 같이 올라가 버린다.
- 원인: `html, body { height: 100% }` 로 body 높이가 화면 높이에 묶여 sticky의 기준이 끝나 버림.
- 막는 법: body에 높이를 묶지 않는다(`min-height` 를 쓴다). 긴 가짜 데이터로 끝까지 내려 보는 확인을 늘 한다.

### Q-02 · 좁은 폭에서 메뉴 묶음 이름이 세로로 깨짐
- 증상: 900px 아래에서 묶음 이름이 한 글자씩 세로로 쌓였다.
- 원인: 새 기능(묶음 접기)을 더하면서 좁은 폭 숨김 규칙이 CSS 우선순위에 밀렸다.
- 막는 법: 기능을 더할 때마다 폰·태블릿·데스크톱 세 폭을 다시 본다. 반응형 규칙은 그 부품 규칙 바로 아래에 둔다(파일 끝에 몰아 두지 않는다).

### Q-03 · 갱신이 입력을 지움
- 증상: 적던 글이 몇 초 뒤 사라진다.
- 원인: 폴링 결과로 화면 전체를 다시 그림.
- 막는 법: F-01.

### Q-04 · 떠 있는 것에 본문이 가림
- 증상: 폰의 떠 있는 탭 줄 밑으로 맨 아래 카드·버튼·뜨는 창이 숨는다.
- 막는 법: 떠 있는 것을 하나 더하면 아래 여백 목록(본문·떠 있는 버튼·뜨는 창·서랍)을 같이 올린다. 안전 영역 포함(L-04).

### Q-05 · 화면에서는 괜찮은데 안 읽힘
- 증상: 회색 안내 글이 대비 3.3:1, 11~11.5px 글자가 곳곳에.
- 막는 법: 토큰 밖 크기·색 금지(T-03), 패널에 대비 숫자 표시(X-01).

### Q-06 · 긴 글이 옆으로 밀거나 겹침
- 증상: 알림 창에서 긴 글이 옆으로 밀리고, 종류 이름과 글 앞머리가 겹쳤다. 목록 점이 카드 테두리 밖으로 나갔다.
- 막는 법: 줄 안 글은 `min-width: 0` + 줄임, 여러 건은 "N건까지 + 외 N건". 가짜 데이터에 아주 긴 글·아주 긴 이름·0건·많은 건을 늘 넣는다.

### Q-07 · 넓지도 좁지도 않은 폭에서 표 오른쪽이 잘림
- 증상: 1100px 같은 중간 폭에서 표 오른쪽이 잘렸다(옆으로 밀기는 좁은 폭에만 있었다).
- 막는 법: 중간 폭에서는 덜 중요한 칸을 숨기고 칸 여백을 줄인다. 옆으로 밀기는 폰 폭만(C-09).
