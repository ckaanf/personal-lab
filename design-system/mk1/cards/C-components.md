# C · 부품

### C-01 · 버튼
- 하는 일: 동작 하나를 누르게 한다.
- 생김새: [아이콘(선택)] 이름. 종류 넷 — 주(채움) · 보통(테두리) · 조용한(테두리 없음) · 위험(빨간 글자). 크기 둘 — 기본 / 작게.
- 상태: 기본 · 올림 · 초점(3px 초점 테두리) · 막힘(흐리게, 누를 수 없음 표시) · 보내는 중(두 번 누름 막음)
- 규칙: 한 화면에 주 버튼은 하나. 글자 링크처럼 생긴 버튼은 만들지 않고 조용한 버튼을 쓴다. 이름은 W-01.
- 토큰: `primary` `primary-hover` `line` `line-strong` `focus` `danger` `r-control` `h-control` `h-control-sm`
- 끝: 키보드 Tab으로 모든 버튼에 초점 테두리가 보이는지, 보내기를 빠르게 두 번 눌러도 한 번만 가는지.
- 이어짐: W-01, F-06

### C-02 · 고르기(덩어리 칩)
- 하는 일: 몇 개 중 하나를 고른다(예: 완료 / 보류 / 되묻기).
- 생김새: 테두리 하나로 묶인 버튼 줄. 고른 것은 주 색 옅은 면 + 주 색 굵은 글자.
- 규칙: 따로 떨어진 칩 여러 개 대신 한 덩어리. 꼭 골라야 하면 고르기 전에는 다음 버튼이 막혀 있다. 0건인 칩은 숨긴다(거르기 칩일 때). 칩은 한 줄, 넘치면 옆으로 밀기.
- 토큰: `line` `primary-soft` `primary` `r-control` `h-control-sm`

### C-03 · 상태 표시(점 + 글자)
- 하는 일: 무엇이 어떤 상태인지 보인다.
- 생김새: ● 7px 점 + 상태 이름. 내 할 일이면 옅은 빨강 면 + 빨간 굵은 글자(면이 붙는 유일한 경우).
- 상태: 뜻마다 점 색(T-02). 정해지지 않으면 `muted`.
- 규칙: 알약(색 면 꼬리표)으로 상태를 쓰지 않는다. 이름은 하나(W-02). 머리 줄·목록·카드 어디서나 같은 모양.
- 토큰: `ok` `hold` `wait` `danger` `info` `muted` `danger-soft` `fs-sm`
- 모두를 위해: 색을 빼도 글자로 읽힌다. 점은 장식(aria-hidden).
- 끝: 흑백 캡처에서 상태가 모두 읽히는지.
- 이어짐: T-02, P-03, C-04

### C-04 · 이름표
- 하는 일: 상태가 아닌 종류·출처를 붙인다(예: "내부만", "AI와 함께", "시안").
- 생김새: 20px 높이, 얇은 테두리, 작은 회색 글자. 색 없음.
- 규칙: 상태(C-03)와 섞지 않는다. 뜻 색을 쓰지 않는다.

### C-05 · 입력 칸
- 하는 일: 글자·고르기를 받는다.
- 생김새: 위에 이름(항상 보임, 자리표시 글자로 이름을 대신하지 않음) → 칸 → 아래 도움말·오류 한 줄.
- 상태: 기본 · 초점(주 색 테두리 + 초점 테두리) · 오류(빨간 테두리 + 아래 글) · 막힘
- 규칙: 여러 줄 글은 처음부터 두 줄 이상 칸. 한 줄 칸에서 Enter가 보내기인지 줄바꿈인지 헷갈리게 하지 않는다.
- 토큰: `line` `primary` `focus` `danger` `r-control` `h-control`

### C-06 · 주고받기 입력 칸(compose)
- 하는 일: 답글·메모·회신을 쓰고 보낸다.
- 생김새: 둥근 상자 안 [글 칸] → 아래 줄 [고르기 칩(C-02)] ··· [보내기]. 받는 사람이 갈리면 칩이 [내부 메모 | 상대에게 답글].
- 상태: 비었음(보내기 막힘) · 쓰는 중 · 내부 메모(칸이 노란 점선) · 공개로 고름("○○에게 보입니다" 줄, 버튼 이름이 "○○에게 보내기"로 바뀜) · 보내는 중
- 규칙: 열 때마다 내부 메모가 기본(P-05). ⌘/Ctrl+Enter로 보내기. 보낸 뒤 다시 기본으로. 앱 어디서나 이 모양 하나(P-02).
- 끝: 아무것도 안 고르고 보내기를 누르면 내부 메모로만 남는지.
- 이어짐: C-07, F-02, P-05

### C-07 · 주고받은 글(말풍선 줄)
- 하는 일: 누가 무엇을 주고받았는지 한눈에 갈리게 한다.
- 생김새: 상대는 왼쪽·따뜻한 면, 나는 오른쪽·차가운 면. 말풍선 위에 동그라미(이름 첫 글자) · 이름 · 시각 · 종류(C-03). 보내기 전 글은 점선 말풍선. 읽음은 마지막 글 밑에 한 줄("읽음 · 시각").
- 규칙: 왼쪽·오른쪽은 앱 전체에서 고정(화면마다 바꾸지 않는다). 같은 글을 두 상자에 두 번 보이지 않는다. 확인 요청 같은 특별한 글은 이름표(C-04)로만 구분. 닫힌 줄은 "주고받은 글 펼치기"로 접는다.
- 토큰: `side-them` `side-me` `r-box` `fs-xs`
- 왜: 한 화면은 상대가 오른쪽, 다른 화면은 왼쪽이었고, 같은 글이 답글과 확인 요청 상자에 두 번 나왔으며 세 가지 색이 섞였다.
- 이어짐: C-06, F-03

### C-08 · 카드(블록)
- 하는 일: 화면 안 한 덩어리를 묶는다.
- 생김새: 머리 줄(이름 · 수 · 기다림 표시 · 도움말 · 접기) → 구분선 → 본문. 본문 항목은 한 줄 모양(번호 동그라미 · 본문 · 메타 줄 · 오른쪽 수정하기/지우기).
- 상태: 펼침 · 접힘(머리 줄만). 접은 상태는 카드 종류별로 기억.
- 규칙: 카드 모양은 하나. 카드 안에 카드를 넣지 않는다(테두리 두 겹 금지). 카드 머리를 누르면 접힌다.
- 토큰: `surface` `line` `r-box` `sp-4`
- 왜: 같은 화면 아래 블록 넷이 서로 다르게 생겨 어수선했고, 상자 안에 카드가 겹쳐 테두리가 두 겹이었다.
- 이어짐: P-02, L-05

### C-09 · 표
- 하는 일: 여러 건을 줄로 비교한다.
- 생김새: 들어간 면의 머리 줄(작은 굵은 회색) · 옅은 선의 줄 · 번호 칸은 고정폭 글꼴.
- 규칙: 0은 비우고, 큰 수는 만·억 단위. 표 기준을 흔드는 특이한 한 줄은 표 밖 한 줄로 뺀다. 좁은 폭에서는 덜 중요한 칸부터 숨기고, 그래도 넘치면 표만 옆으로 밀기(화면 전체가 밀리면 안 됨). 머리 줄은 스크롤해도 붙어 있다.
- 왜: 4,826,678,406 같은 숫자와 0 칸이 빽빽했고, 큰 한 줄이 막대 기준을 흔들었다.
- 이어짐: Q-01, Q-02

### C-10 · 창(모달)
- 하는 일: 짧은 결정 하나를 받는다.
- 생김새: 제목 → 칸 몇 개 → 오른쪽 아래 [닫기(조용한)] [주 동작(주)].
- 규칙: 주 동작 이름 = 창 제목 = 그 창을 연 버튼 이름. 이유가 필요한 결정(보류·제외)은 이유 칸을 필수로. 창에 적은 메모가 바깥에 보이면 "메모는 ○○에게도 보입니다"를 붙인다. Esc로 닫힌다.
- 토큰: `surface` `shadow-pop` `r-box` `sp-5`

### C-11 · 새 소식 목록
- 하는 일: 새로 온 것을 한곳에서 본다.
- 생김새: 종 아이콘 + 빨간 점(수는 선택) → 누르면 뜨는 창: 줄마다 점 · 종류 · 글 앞머리(두 줄까지) · 시각, 위에 "모두 읽음".
- 규칙: 긴 글이 옆으로 밀리지 않게 줄여 자른다. 같은 종류가 여러 건이면 "3건까지 적고 외 N건".
- 이어짐: F-03, L-01
