# X · 도구

디자인을 정하고 지키는 데 쓰는 페이지·양식. mk1에서 실제로 만든다.

### X-01 · 조종 패널(값 고치기)
- 하는 일: 토큰 값을 화면 옆에서 직접 움직여 보고 정한다. 문서로 먼저 정하지 않는다.
- 생김새: 오른쪽에 붙어 따라오는 340px 패널(좁은 폭은 아래로).
  - 머리: [처음 값으로] [토큰 파일 복사] · 결과 한 줄("복사했습니다. 바꾼 값 N개")
  - 묶음별(토큰 파일의 묶음 주석) 줄: 사람이 읽는 이름 + 토큰 이름 + 조작 칸
  - 조작 칸은 값 종류로 저절로: 색 → 색 고르기 + 글자 칸 / px → 슬라이더 + 숫자 / 수(줄 간격·굵기) → 슬라이더 + 숫자 / 그 밖 → 글자 칸
  - 바꾼 줄은 이름 옆 • 표시
- 동작: 토큰 파일을 읽어 줄을 만든다(토큰을 더해도 패널 코드는 안 고친다). 바꾸면 바로 화면에 반영(`:root`에 덮어쓰기). 바꾼 값은 이 브라우저에 기억. "복사"는 원본 파일에서 바꾼 값만 갈아 끼운 전체 파일을 클립보드로 → 사람이 붙여 넣어 커밋.
- mk1에 더할 것: 밝은 / 어두운 모드 바꾸기(모드별 값 따로), 대비 숫자를 줄 옆에 바로 표시(4.5 미만 경고), 폰 폭 미리 보기, 플랫폼 중립 원본(`tokens.json`)으로 내보내기.
- 끝: 토큰 하나를 파일에 더하고 패널을 열면 줄이 저절로 생기는지, 복사한 파일을 붙여 넣었을 때 diff가 바꾼 값만인지.
- 이어짐: X-02, T 전체

### X-02 · 부품 한 장 보기
- 하는 일: 모든 토큰과 부품을 한 페이지에서 본다. 조종 패널을 붙이면 값 변화가 부품 전체에 바로 보인다.
- 생김새: 문구 규칙(✗ / ✓ 예) → 색(역할·뜻 색·면·선) → 글자 5단 → 둥글기·간격 → 버튼 → 고르기 → 상태(지금 / 기준 나란히) → 이름표 → 입력 → 카드·표 → 말풍선 줄 → 창 → 틀(윗줄·메뉴·탭 줄 축소판).
- 규칙: 페이지 전용 부품은 접두사로 나눠 실제 부품과 섞지 않는다. 승인되면 부품 파일로 옮긴다.
- 이어짐: X-01, C 전체

### X-03 · 시안: 지금 / 바뀐 뒤
- 하는 일: 만들기 전에 무엇이 어떻게 바뀌는지 합의한다(P-06).
- 생김새: 위 조작 줄(사용자 종류 · 폭 데스크톱/폰 · 상태 바꾸기) → "지금" 과 "바뀐 뒤" 나란히(폰은 375px 두 개) → 아래 바뀌는 것 목록.
- 규칙: 시안 전용 CSS는 접두사. 실제 데이터 대신 가짜 데이터(실제 회사·사람 정보 금지). 승인된 시안 파일은 남겨 두고 기록에 링크한다.

### X-04 · 화면 점검표
- 하는 일: "어수선하다"를 고칠 목록과 숫자로 바꾼다.
- 생김새: 머리에 날짜 · 본 폭 · 본 계정 · 기준(어떤 원칙으로 봤나) · 숫자(걸리는 곳 N, 높음/중간/낮음). 표: `# | 어디 | 무엇이 걸리나 | 고치는 방향 | 무게`, 고치면 `✓`. 끝에 "고칠 순서 제안"과 "이번에 바로 고친 것".
- 나란히 보기 표: 화면들을 열로, 머리 줄·단계 줄·할 일·카드·오른쪽 칸을 행으로 → 다른 칸이 통일 대상.
- 이어짐: P-02, P-06
