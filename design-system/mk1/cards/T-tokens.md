# T · 토큰

화면은 토큰만 쓴다. 직접 쓴 색·크기는 0개가 목표다(X-04로 센다).
원본은 플랫폼 중립 값(mk1에서 `tokens.json` 같은 파일)으로 두고, 웹은 CSS 변수, 앱은 그 플랫폼 상수로 뽑는다.
아래 값은 시작점일 뿐이고, 정하는 일은 조종 패널(X-01)에서 한다.

### T-01 · 색은 역할로
- 하는 일: 색을 "무슨 색"이 아니라 "무엇에 쓰는 색"으로 부른다.
- 생김새:
  - 글자 3단: `ink`(본문) · `ink-2`(보조) · `ink-3`(가장 흐림, 그래도 4.5:1)
  - 면 4단: `bg`(바탕) · `surface`(카드) · `sunken`(들어간 면·표 머리) · `neutral-soft`(회색 면)
  - 선 3단: `line` · `line-2`(옅은) · `line-strong`(진한)
  - 주 색 1개 + `primary-hover` · `primary-soft` · `focus`(초점 테두리)
  - `on-fill`: 채운 면 위 글자
  - 쪽: `side-them`(상대 말풍선, 따뜻한 옅은 면) · `side-me`(내 말풍선, 차가운 옅은 면)
  - 코드 상자: `code-bg` · `code-ink`
- 규칙: 주 색은 하나. 주 색은 주 버튼·고른 것·초점에만. 프로젝트마다 주 색 하나만 바꿔 끼울 수 있게 다른 토큰이 주 색에 기대지 않는다.
- 이어짐: T-02, T-06

### T-02 · 뜻 색 = 색 · 면 · 선 세 벌
- 하는 일: 상태의 뜻을 색으로 돕되, 색만으로 전하지 않는다.
- 생김새: 뜻마다 세 벌 — `ok`(완료) · `hold`(보류) · `wait`(기다림·되물음) · `danger`(내 할 일·오류·지우기) · `info`(진행·검토) · `accent`(특별 기능) · `muted`(끝·제외)
  - `<뜻>`: 점과 글자 색 / `<뜻>-soft`: 아주 옅은 바탕 / `<뜻>-line`: 옅은 바탕의 테두리
- 규칙: 뜻 색은 점과 글자에만. 면(soft)은 "내가 할 일"이나 알림 상자처럼 눈을 끌어야 할 때만. 빨강은 "내가 지금 할 일"과 오류에만 써서 아껴 둔다.
- 끝: 흑백으로 캡처해도 상태가 글자로 구분되는지.
- 왜: 상태가 여섯 가지 색 알약이어서 화면이 알록달록했고, 색을 못 가리는 사람은 구분할 수 없었다. 점 + 글자로 바꾸고 면은 내 할 일에만 남겼다.
- 이어짐: C-03

### T-03 · 글자 5단계
- 생김새: `fs-xs 12` · `fs-sm 13` · `fs-md 14`(기본) · `fs-lg 16`(소제목) · `fs-xl 20`(제목) / 굵기 3단 `normal 400` · `strong 600` · `title 700` / 줄 간격 `lh 1.55`
- 규칙: 단계 사이 값(11.5px 같은 것)을 만들지 않는다. "편하게" 보기(L-06)에서는 기본이 16으로 한 단계씩 오른다.
- 모두를 위해: 바깥 사용자 기본은 "편하게". 12px은 시각·작성자 같은 메타에만.

### T-04 · 둥글기 3단계 + 동그라미
- 생김새: `r-control 6`(버튼·입력·꼬리표) · `r-box 10`(카드·상자·말풍선·창) · `r-round 999`(점·얼굴·떠 있는 탭 줄만)
- 규칙: 부품 종류로 둥글기가 정해진다. 화면마다 새 값을 만들지 않는다.

### T-05 · 간격 4의 배수 · 높이 · 그림자
- 생김새: `sp-1 4` · `sp-2 8` · `sp-3 12` · `sp-4 16` · `sp-5 24` · `sp-6 32` / `h-control 32` · `h-control-sm 28` / `shadow-pop`(떠 있는 창 하나)
- 모두를 위해: 누르는 곳은 폰에서 44px 이상(앱 관례). 웹의 32px 버튼은 폰 폭에서 키운다.

### T-06 · 밝은 / 어두운 모드
- 하는 일: 같은 토큰 이름으로 두 모드를 갈아 끼운다.
- 규칙: 어두운 모드는 색을 뒤집는 게 아니라 역할마다 다시 고른다. `surface`가 `bg`보다 밝다(떠 있는 느낌). 뜻 색은 어두운 바탕에서 4.5:1이 되게 밝힌다. 그림자 대신 선으로 층을 나눈다. 시스템 설정을 따르고, 사람이 고르면 그 값을 기억한다.
- 끝: 두 모드에서 X-02 한 장 보기를 열어 대비가 모두 4.5 이상인지.
- 이어짐: X-01(패널에서 모드를 바꿔 가며 값 조정)
