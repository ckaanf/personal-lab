# L · 틀

폭 기준: 폰 < 900px ≤ 태블릿·좁은 창 < 1200px ≤ 데스크톱. 앱이면 폰 = 컴팩트, 태블릿 = 레귤러 폭.

### L-01 · 윗줄
- 하는 일: 어디에 있는지, 무엇을 찾고, 무엇이 새로 왔는지, 내 계정을 한 줄에서.
- 생김새: [☰] [위치(브랜드 › 지금 화면)] ··· [찾기 칸] [+] [🔔 + 빨간 점] [내 동그라미]
  - ☰: 왼쪽 메뉴 접기·펴기(데스크톱), 서랍 열기(폰)
  - 찾기: 아무 화면에서 `/` 키로 초점(F-04)
  - +: 그 사용자가 가장 자주 새로 만드는 것 하나
  - 내 동그라미: 이름 첫 글자 → 누르면 이름·역할, 설정, 비밀번호 바꾸기, 나가기
- 규칙: 글자 버튼을 줄줄이 늘어놓지 않는다. 계정 일은 동그라미 메뉴 한곳에. 아이콘 버튼에는 툴팁과 접근성 이름.
- 폰: 위치를 숨기고 찾기는 돋보기 → 누르면 윗줄 전체가 찾기 칸.
- 끝: 375px에서 윗줄이 한 줄에 들어가는지(넘침 0).
- 왜: 오른쪽에 글자 버튼 다섯(소식·이름·의견·비밀번호·나가기)이 있어 폰 폭에서 넘쳤다.
- 이어짐: C-11, F-03, F-04, L-02

### L-02 · 왼쪽 메뉴(펼침 · 접힘)
- 하는 일: 화면 사이를 옮긴다.
- 생김새:
  - 펼침(약 220px): 묶음 이름(누르면 접힘 ▾) → 항목 [아이콘 20 · 이름 · 숫자 배지]. 높이 40, 지금 화면은 들어간 면 + 굵게 + 아이콘 주 색.
  - 접힘(약 76px): 아이콘 22 **밑에 짧은 이름**(11~12px, 두 글자~네 글자). 배지는 아이콘 오른쪽 위.
- 상태: 펼침 · 접힘 · 지금 화면 · 올림 · 배지 있음
- 규칙: 접어도 이름은 남긴다(아이콘만 남기지 않는다). 접힘에는 자주 쓰는 것 몇 개 + "더보기". 펼침·접힘은 사람마다 기억, 키 `[`.
- 토큰: `surface` `sunken` `ink-2` `primary` `danger`(배지) `r-box`
- 모두를 위해: 아이콘만으로는 뜻을 추측해야 해서 여러 연령대 기준에 맞지 않는다(P-01).
- 왜: 처음엔 아이콘 대신 기호를 썼다가 어수선해서 글자만 → 접으면 첫 글자로 바꿨고, 그것도 읽히지 않아 "아이콘 + 짧은 이름"으로 갔다.
- 이어짐: L-03, L-04

### L-03 · 메뉴 묶음 접기
- 하는 일: 메뉴가 길어도 필요한 묶음만 펼쳐 둔다.
- 규칙: 묶음마다 접고 펼침, 사람마다 기억. 지금 보는 화면이 든 묶음은 늘 펼친다. 접힌 묶음 안에 알림이 있으면 묶음 이름 옆에 점.
- 끝: 묶음을 다 접고 알림을 하나 만든 뒤 점이 보이는지, 접힌 묶음 속 화면으로 가면 그 묶음이 펼쳐지는지.
- 이어짐: Q-02(좁은 폭에서 묶음 이름 깨짐)

### L-04 · 폰: 떠 있는 유리 탭 줄 + ☰ 서랍
- 하는 일: 폰에서 자주 쓰는 곳은 엄지로, 나머지는 서랍으로.
- 생김새:
  - 탭 줄: 아래에서 떠 있는 알약(좌우 12, 아래 14 + 안전 영역, 높이 68, 동그라미 둥글기). 반투명 면 + 뒤 흐림·채도 올림 + 흰 윗선 + 부드러운 그림자.
  - 탭: 아이콘 + **늘 보이는 이름**. 지금 탭은 안쪽에 더 밝은 유리 방울(둥근 면 + 작은 그림자).
  - 탭 4~5개, 사용자 종류마다 다르게. 마지막은 "더보기" 또는 ☰.
  - 서랍: ☰ → 왼쪽에서 나오는 280px 판(펼친 메뉴 L-02 그대로) + 뒤 어둡게. 바탕을 누르면 닫힘.
- 상태: 기본 · 지금 탭 · 배지 · **투명도 줄이기 켬**(불투명 면, 흐림 없음) · 서랍 열림
- 규칙: 떠 있는 탭 줄에 가리지 않게 본문·떠 있는 버튼·뜨는 창의 아래 여백을 탭 줄 높이만큼 올린다. 안전 영역(`env(safe-area-inset-bottom)`)을 더한다.
- 웹 구현 메모: `backdrop-filter: blur(18px) saturate(180%)`, 면은 `color-mix(surface 55%, transparent)`, `@media (prefers-reduced-transparency: reduce)` 에서 불투명. 앱이면 플랫폼 머티리얼을 쓰고 "투명도 줄이기" 접근성 설정을 따른다.
- 끝: 흰 카드 위·사진 위 둘 다에서 탭 이름이 읽히는지, 투명도 줄이기를 켜면 불투명해지는지, 맨 아래 카드가 탭 줄에 가리지 않는지.
- 이어짐: L-02, Q-04

### L-05 · 상세 화면 틀
- 하는 일: 어떤 상세 화면이든 같은 순서로 읽게 한다(P-02).
- 생김새(위에서 아래):
  1. 머리 줄: 목록 · ◀ n/N ▶ · 번호 · 제목 · 상태(C-03) · 보기 설정(L-06) · 정보 칸 버튼 — 스크롤해도 붙어 있음
  2. 단계 줄 카드: 지난 › **지금** › 앞으로 단계
  3. 지금 할 일 카드: 문장 하나 + 주 버튼 하나(나머지는 "더 보기") — P-03
  4. 가운데 넓은 본문: 카드(C-08)들. 끝난 단계는 한 줄 요약으로 접고, 앞으로 단계는 "미리 보기"로 접는다
  5. 오른쪽 정보 칸: 오른쪽에서 여는 패널, 기본 접힘(키 `]`). 맨 위 정보, 그 아래 기록(접힘)
- 규칙: 머리 줄 정보는 번호·제목·상태·긴급도까지. 나머지는 정보 칸. 단계는 한 곳에만(머리 줄과 오른쪽에 두 번 쓰지 않는다). 좁은 폭(1000px 아래)은 한 칸으로 쌓는다.
- 끝: 상세 화면들을 나란히 놓고 다섯 칸이 같은지(X-04 표).
- 왜: 머리 한 줄에 정보 약 10가지, 오른쪽에 카드 8개가 늘 쌓여 있었다. 할 일이 세 곳에 나뉘어 있었다.
- 이어짐: P-02, P-03, C-08, L-06

### L-06 · 보기 설정: 편하게 / 촘촘하게
- 하는 일: 같은 화면을 사람마다 읽기 편한 밀도로.
- 생김새: 머리 줄 같은 자리의 고르기(C-02).
  - 편하게: 본문 16px · 넉넉한 여백 · 주고받은 글 펼침
  - 촘촘하게: 14px · 주고받은 글 한 줄 요약 · 반복 안내 숨김
- 규칙: 기본값은 사용자 종류별(바깥 사용자는 편하게, 매일 많이 보는 내부 사용자는 촘촘하게). 바꾸면 기억. 모든 상세 화면 같은 자리에. 그림 안의 좌표(핀 등)가 걸린 영역은 보기 설정과 따로 확대 비율(50~200%, 5% 단위)을 둔다.
- 이어짐: T-03, P-01
