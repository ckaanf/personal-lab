# 시험: 개인 재정 앱에 mk1 입히기 (2026-10-30)

mk1(업무 포털에서 나온 시스템)이 성격이 다른 개인 폰 앱에서도 통하는지 본 시험. 원본·배포는 건드리지 않았다(시험 코드는 개인 앱 저장소의 `try/mk1` 브랜치).
화면은 **가짜 기록**으로 띄웠다. 숫자는 모두 390px 폭, 화면 글자 67곳 기준.

## 대상

한 화면짜리 폰 앱. 머리(제목 · 달 고르기 · 설정) → 큰 숫자 카드 → 설정식 목록 줄(할 일 · 묶음 · 기록) → 진행 막대 → 떠 있는 "+ 기록" 버튼 → 아래에서 올라오는 시트 · 되돌리기 알림.
기존 공통 디자인(v0.1): 종이색 · 남색 · 모서리 20px · 제목 글꼴 따로.

## 1단계 — 값만(프리셋)

공통 디자인의 토큰 이름에 mk1 값을 대응시킨 CSS 한 장(`shared/presets/mk1.css`)을 공통 CSS 뒤에 덧붙였다. 부품은 그대로.

| 잰 것 | 전 | 후 |
|---|---|---|
| 대비 4.5 미만 글자(밝게) | 16 | **0** |
| 대비 4.5 미만 글자(어둡게) | 0 | 0 |
| 12px 글자 | 16 | 0 (보조 글자 13px) |
| 고친 파일 | — | CSS 1장 + 배포 스크립트 3줄 |

- 폰이라 글자는 mk1 "편하게" 단계(13 · 14 · 16 · 18 · 22)를 썼다.
- mk1 에 없는 값: 큰 숫자(38px), 제목 글꼴 → 원래 값·본문 글꼴로 둠.
- 값은 mk1 `tokens.json` 을 손으로 옮겼다. 계속 쓸 거면 빌드가 프리셋 CSS 를 뽑아야 한다(지금은 두 곳에 같은 값).

## 2단계 — 블록 부탁

부탁 문장: **"mk1_L-04 + mk1_C-03 + mk1_Q-04 를 재정 앱에"**

- L-04: "도구" 목록 세 줄을 아래 유리 탭 줄(결산 · 사다리 · 지도 · 시뮬레이터)로.
- C-03: 할 일 상태를 "✓ 글자" → 점 + 글자(된 것 초록 점, 남은 것 기다림 점).
- Q-04: "+ 기록" 버튼을 탭 줄 위로, 알림을 그 위로, 본문 아래 여백을 늘림. 확인: 버튼이 탭 줄에 겹침 없음, 맨 아래 기록 줄이 버튼에 가리지 않음.

| 잰 것 | 값 |
|---|---|
| 다시 고친 횟수 | 0 (첫 판이 그대로 됨, 밝게·어둡게 확인) |
| 카드 밖에서 내가 정한 것 | 5 — 글자 단계 고르기, 큰 숫자 값, 탭 이름, 도구 목록 빼기, 버튼과 탭 줄 쌓는 순서 |
| mk1 부품 CSS 를 통째로 얹기 | **불가** — 클래스 이름 12개 겹침(`card` `btn` `seg` `field` `toast` `app` `muted` `note` `num` `done` `warn` `icon-btn`). 겹치지 않는 블록(`tabbar` `tab` `st`)만 옮김 |

## 카드에 없음 (폰 앱 부품 8)

큰 숫자 · 설정식 목록 줄 · 떠 있는 주 버튼(탭 줄과 함께일 때 자리) · 아래에서 올라오는 시트 · 진행 막대 · 달 고르기(‹ 달 ›) · 되돌리기 알림 · 단위 붙은 숫자 입력 칸

## 뼈대가 맞은 것 / 안 맞은 것

- 맞음: L-04 탭 줄, C-03 상태, Q-04, T 토큰 전부(프리셋), P-01 기준.
- 안 맞음: L-01 윗줄(찾기 · + · 새 소식 · 계정은 혼자 쓰는 한 화면 앱에 과함), L-02·L-03 왼쪽 메뉴, L-05 상세 틀 — 모두 여러 화면 · 여러 사람 업무 포털용.
- 걸린 것: 탭 줄과 떠 있는 버튼이 겹쳐 쌓여 아래쪽 약 180px 를 차지한다. 주 버튼을 탭 줄 안으로 넣을지(가운데 +) 같은 판단이 카드에 없다.

## 판단 재료

- **값(프리셋)은 그대로 통했다.** CSS 한 장으로 대비 문제 16곳이 0곳. "프리셋 여러 벌"은 이 층에서는 싸다.
- **뼈대는 반만 통했다.** 탭 줄 · 상태 · 가림 규칙은 맞고, 업무 포털 틀(윗줄 · 메뉴 · 상세)은 안 맞고, 폰 앱 부품 8개가 비어 있다.
- **부품 CSS 는 이름 앞에 시스템 표시가 없어 섞어 쓸 수 없다.** 블록 단위로 가져다 쓰려면 블록별 CSS 나 이름 구분이 필요하다.
