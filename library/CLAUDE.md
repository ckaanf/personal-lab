# library/ — 에이전트 안내

백엔드 도서관. 사람용 설명은 [README.md](README.md).

## 규칙
- 한국어로 답한다.
- **체급 모드가 기본**: 사용자가 카드를 꺼내면 답부터 주지 않는다. 이론 질문에 먼저 답하게 하고, 실습은 숫자를 먼저 예측받은 뒤 잰다. 사용자의 설명에서 틀린 곳만 짚는다. 정리 노트를 대신 쓰지 않는다.
- AI가 해도 되는 것: 실습 무대(docker-compose, 장애 주입, 부하 스크립트, 가짜 외부 시스템), 측정 도구, 카드 보강. "손으로" 칸의 코드는 쓰지 않는다.
- 카드 ID(`DB-02` 등)는 바꾸지 않는다. 카드를 없앨 때는 지우지 말고 제목 뒤에 `(버림: 이유)`.
- 공개 레포다: 회사 정보, 개인 재정, 강의 구매 내역, 볼트 내용은 넣지 않는다.

## 볼트와의 관계
- 사용자의 기록은 볼트 `Notes/실험기록/`에 사용자가 쓴다. 노트 맨 위 `library: <카드ID>`로 이 레포를 가리킨다.
- 어떤 카드를 이미 했는지 알고 싶으면 볼트에서 `grep -rl "library: DB-02" Notes/` 로 찾는다 (볼트 경로: 회사 맥 `~/Personal/vault`, 서버 `~/vault/Vault`).
- 지금 꺼내 둔 카드는 볼트 `방향.md`의 학습 줄에 한 줄로 적는다 (한 번에 하나).

## 새 카드·서가를 더할 때
- 카드를 더하거나 고치면 볼트 목차를 다시 만든다: `python3 library/tools/vault_index.py > <볼트>/도서관.md` (볼트 파일은 손으로 고치지 않는다).
- 사용자가 실제로 부딪힌 곳(회사 일반화, 홈서버, Media Lab)에서 나온 것만 더한다. 목록을 늘리려고 더하지 않는다.
- README의 서가 표 카드 수를 맞춘다.
