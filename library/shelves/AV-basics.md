# AV · A/V 기초

### AV-01 · 영상 한 장의 크기
- 장면: 1080p 30fps 원본을 그대로 보내려다 대역폭 계산이 안 맞음.
- 이론: 해상도 × 프레임 × 픽셀당 바이트, 색공간(YUV)과 크로마 서브샘플링(4:2:0), 압축률.
- 답해 볼 것: ① 1080p30 비압축 초당 바이트 ② 4:2:0이 줄이는 비율 ③ RGB가 아니라 YUV를 쓰는 이유
- 읽을 곳: "Digital video introduction"(GitHub leandromoreira/digital_video_introduction)
- 실습: 원본·4:2:0·H.264 크기를 먼저 계산하고 FFmpeg로 확인
- 손으로: 계산표
- 끝: 볼트에 3줄

### AV-02 · 오디오 기초
- 장면: 소리가 지직거림 / 마이크와 영상이 조금씩 벌어짐.
- 이론: 샘플레이트·비트 깊이·채널, 오디오 버퍼 크기와 지연, 오디오는 끊기면 바로 티가 난다(영상보다 민감).
- 답해 볼 것: ① 48kHz에서 버퍼 480샘플이면 몇 ms ② 버퍼가 작으면 생기는 일 ③ 샘플레이트가 다른 두 장치를 섞으면
- 읽을 곳: 같은 저장소의 오디오 부분 · Web Audio API 문서
- 실습: 버퍼 크기별 지연·끊김 측정
- 손으로: 지연 계산 함수
- 끝: 볼트에 3줄

### AV-03 · 타임스탬프와 립싱크
- 장면: 입은 움직이는데 소리가 늦게 들림.
- 이론: PTS·DTS, 오디오를 기준 시계로 영상을 맞추는 이유, 허용 범위(대략 수십 ms), 드리프트.
- 답해 볼 것: ① PTS와 DTS가 다른 경우 ② 영상이 아니라 오디오를 기준으로 하는 이유 ③ 드리프트를 고치는 법
- 읽을 곳: ITU-R BT.1359(립싱크 허용 범위) 요약 · FFmpeg 문서 `-async`·`aresample`
- 실습: 오디오를 일부러 100ms 늦춰 체감 확인, 타임스탬프로 되돌리기
- 손으로: 어긋남 측정 방법
- 끝: 볼트에 3줄

### AV-04 · 컨테이너와 코덱 구분
- 장면: mp4인데 재생이 안 됨 / 같은 영상인데 브라우저마다 됨·안 됨.
- 이론: 컨테이너(mp4·ts·webm·fmp4)와 코덱(H.264·HEVC·AV1·Opus·AAC)은 다르다, 브라우저 지원표, `ffprobe`로 보기.
- 답해 볼 것: ① 컨테이너가 담는 것 ② fmp4가 스트리밍에 쓰이는 이유 ③ 코덱을 고를 때 볼 것(지원·라이선스·인코딩 비용)
- 읽을 곳: MDN "Media container formats" · "Web video codec guide"
- 실습: 같은 영상을 컨테이너·코덱 조합 4개로 → 크기·인코딩 시간·브라우저 재생 확인
- 손으로: `ffprobe` 결과 읽기 메모
- 끝: 볼트에 3줄
