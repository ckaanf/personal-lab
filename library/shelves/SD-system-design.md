# SD · 시스템 설계 연습

> 다른 서가의 카드를 엮는 연습. 한 문제 = 요구 → 숫자 추정 → 설계 → 병목 → 장애 → 내 말로 설명.

### SD-01 · 숫자 감각 (어림셈)
- 장면: "하루 1천만 요청이면 서버 몇 대?"에 바로 답이 안 나옴.
- 이론: 지연 숫자(메모리·SSD·네트워크·대륙 간), 초당으로 바꾸기(하루 ≈ 10만 초), 저장량·대역폭 계산.
- 답해 볼 것: ① 하루 1천만 요청의 초당 평균·피크 ② 1KB × 1억 건 ③ 대륙 간 왕복
- 읽을 곳: Jeff Dean "Latency Numbers" · 『가상 면접 사례로 배우는 대규모 시스템 설계 기초』 2장
- 실습: 문제 5개를 먼저 어림하고 계산기로 확인
- 손으로: 내 숫자 카드 한 장
- 끝: 볼트에 3줄

### SD-02 · 연습 문제: 결제·지갑
- 장면: (면접·설계 리뷰) "충전·결제·환불이 되는 지갑을 설계해 보세요."
- 이론: TX 서가 전체 — 원장, 멱등, 외부 PG, 대사.
- 답해 볼 것: ① 잔액을 저장할까 원장 합으로 할까 ② 외부 PG 장애 시 ③ 하루 정산
- 읽을 곳: 『가상 면접 사례로 배우는 대규모 시스템 설계 기초 2』 결제 장 · 결제 정합성 실험실
- 실습: 45분 타이머로 설계를 그리고, 실험실 결과와 비교해 빠진 것 찾기
- 손으로: 설계 그림 한 장
- 끝: 볼트에 3줄

### SD-03 · 연습 문제: 라이브 스트리밍 + 채팅
- 장면: "1만 명이 보는 라이브와 채팅을 설계해 보세요."
- 이론: MS·MD·FO·RT 서가 — 받기, 트랜스코딩, CDN, 채팅 팬아웃, 후원 정합성.
- 답해 볼 것: ① 지연 목표에 따라 바뀌는 구조 ② 비용이 가장 큰 곳 ③ 인기 방 하나가 몰리면
- 읽을 곳: 위 서가들
- 실습: 45분 설계 → 각 서가 카드로 근거 붙이기
- 손으로: 설계 그림 한 장
- 끝: 볼트에 3줄

### SD-04 · 연습 문제: 선착순·재고
- 장면: "1분 안에 10만 명이 몰리는 선착순 쿠폰을 설계해 보세요."
- 이론: CC-05(분산 락), CA-04(Redis), API-04(속도 제한), FO-04(접속 폭주), 대기열.
- 답해 볼 것: ① 초과 발급을 막는 지점 ② DB 앞에서 걸러 내는 법 ③ 공정성(먼저 온 사람)
- 읽을 곳: 위 카드들
- 실습: 설계대로 작게 구현해 부하를 넣고 초과 발급 0과 처리량 확인
- 손으로: 핵심 발급 로직
- 끝: 볼트에 3줄
